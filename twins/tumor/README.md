# Tumor twin

Reproduces TumorTwin: a patient-specific reaction–diffusion model of high-grade glioma is calibrated to MRI and then
predicts the tumor under different chemotherapy doses. Not yet on dtcore or the page: one calibration takes about
half an hour, and without a toxicity cost there is no real decision to make.

## Sources
- Kapteyn, Chaudhuri, Lima, Pash, Bravo, Willcox, Yankeelov, Hormuth 2026, *BMC Medical Informatics and Decision
  Making* 26:237 (arXiv 2505.00670).
- OncologyModelingGroup/TumorTwin @ `bedf90a` (2026-04-07), fetched by `fetch_upstream.sh`.
  **UT Austin Research License: academic and research use only.**

## Six elements

| S | O | D | Q | U | R |
|---|---|---|---|---|---|
| 3D tumor cell density | MRI (ADC → cellularity), 10 visits | calibrated (d, k, α_RT, α_CT), point estimate | total tumor cell count over time | chemotherapy dose | none yet (no toxicity cost) |

## Files
- `scripts/repro_hgg.py` — the upstream HGG demo tutorial as a script → `results/HGG_demo_001/repro.json`.
- `scripts/sample_sims.py`, `merge_sims.py`, `surrogate_experiments.py` — training simulations and a Gaussian-process
  surrogate (in progress).
- `hpg/` — Slurm job scripts and a guide for running the simulations on a cluster.
- `experiments/2026-10-13_pilot_inverse/` — can a small network read the parameters straight from MRI summaries?

## Setup (separate environment: PyTorch, Python 3.10–3.11)
```bash
cd twins/tumor
./fetch_upstream.sh
python3.11 -m venv .venv && source .venv/bin/activate
pip install torch scikit-learn -e upstream/TumorTwin
```

## Run (from twins/tumor)
```bash
python scripts/repro_hgg.py HGG_demo_001         # ~31 min on 2 CPU cores
python scripts/sample_sims.py --n 256 --seed 0   # training simulations, ~2 h on 2 cores (cluster: hpg/README.md)
python scripts/sample_sims.py --truth            # the true parameters at each dose: the reference decision
python scripts/surrogate_experiments.py          # train the surrogate, calibrate with it, data-size experiment
```

## Results (HGG_demo_001)
- Calibrating 4 parameters (d, k, α_RT, chemo sensitivity) on the first 5 MRIs gives (0.1000, 0.0500, 0.0500, 0.2001)
  against the true (0.1, 0.05, 0.05, 0.2): error < 0.03 %.
- Total cell count at visits 6–10 (not used for calibration) is predicted within 0.01 %.
- Total chemo dose 30 → 70: cell count on day 270 falls from 3.17e11 to 2.31e11, monotonically.

## Notes
- The demo data are generated by the same model without noise (the paper: "idealized … no noise in the calibration
  data"), so these accuracies do not carry over to real patients.
- Cell 22 of the upstream tutorial swaps the parameter labels: parameter 0 is d, not k (see the unpacking order in
  `update_model_and_predict`).
- `ChemotherapySpecification` renormalises by the largest single dose in its constructor: construct it first, then
  change `ct.doses`.
